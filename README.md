# 🚗 Travelgo - Travel Booking Portal

Travelgo is a Python Flask-based web application designed to simplify travel bookings for flights, trains, and buses.

## 🌟 Features
* User Registration and Login
* Ticket Booking System for Flights, Trains, and Buses
* View Personal Bookings (`My Bookings` page)
* Flash Messages for Booking Success and Errors

## 🛠️ Tech Stack
* **Backend:** Python (Flask)
* **Frontend:** HTML5, CSS3
* **Tools:** Git, GitHub, VS Code
